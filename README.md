# PPS DPG Lumi Plot tools

Open this project in SWAN for easy usage!

[![SWAN](https://swanserver.web.cern.ch/swanserver/images/badge_swan_white_150.png)](https://swan.cern.ch/hub/spawn?software_source=lcg&use-local-packages=true&use-jupyterlab=true&lcg=LCG_110_swan&cores=4&memory=16&platforms=x86_64-el9-gcc13-opt&projurl=https://github.com/AndreaBellora/pps-dpg-lumi-plots.git)

Tested with SWAN software stack '110'. No special requirements on number of cores, memory or Spark cluster features. Remember to check the 'Use Python packages installed on CERNBox' box, in order to update and use the latest version of the mplhep package (compatible with the LCG110 matplotlib), over the version available in the stack, which is not compatible.
